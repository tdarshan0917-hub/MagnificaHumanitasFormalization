## Deposit steps

1. Create a Zenodo upload and add the four files. Enter the prepared metadata; set the publication date to the actual first public release date.
2. If the work has no DOI, Zenodo can reserve one in the draft. A reserved DOI is registered when the record is published. Review the title, author, rights, files and visibility before publishing.
3. Publish the reviewed record. Record its DOI and URL with the citation. File changes after publication follow Zenodo's current editing/version rules; retain the exact package identified by the published record.
