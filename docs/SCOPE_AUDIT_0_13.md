## Construction and actual composition

DistributedControl.lean has two concrete finite case constructors: process is a ConsultationProcess for a benefits-denial pause protocol, and controllers is an OversightSystem whose intervention condition is computed from each role changing its own input. Existing Bool/Option Bool carriers encode two separate external controls: operator and independent board. True protocol output means temporary suspension, not benefit award. Recognition, board independence and review/remit are supplied as case evidence. Each external control is separately proved effective in the same composition; neither actor can clear the other's asserted hold.

The community's request is accepted, faithfully recorded and amendable. Before repair that request never affects the pause for any external setting. After repair a true local pause request is honored for every external setting, while both external controls remain effective. With no holds and no local request, the protocol still resumes; the repair is not a constant True output. The same original affected high-impact denial, identified assignment, appeal and remedy-capacity fragments accompany both versions.
