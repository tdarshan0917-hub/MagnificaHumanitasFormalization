# Countermodel protocol

Every proposed non-implication is quantified over a declared model class. A single scenario only refutes a universal implication if it satisfies all the stated background assumptions.

| ID | Separation | Background to preserve | Critical limitation |
|---|---|---|---|
| C1 | Disclosure does not ensure answerability | Shared ontology; declared transparency specification | May fail full compliance: name the fragment, not the whole theory |
| C2 | Human review does not ensure appeal | Review semantics, real reviewer and affected person | A full theory may require appeal; absence then describes a violation |
| C3 | Identified assignment does not ensure remedy capacity | Responsibility and identification requirements | If accountability is defined to include remedy, use narrower responsibility predicate |
| C4 | Explanation does not ensure an adopted fairness criterion | Nontrivial explanation and independently specified fairness test | An unconstrained `Justice := False` demonstrates no useful policy fact |
| C5 | Distributed control does not ensure local agency | At least two actual controllers and a lower-level community | Need an operational local-agency criterion; defer until justified |
| C6 | Consultation does not ensure final authority | Real participation channel and explicit decision rule | Mere `Participatory := True` is insufficient for an informative example |

## Required evidence per result

- Model's finite carrier types and all interpretations.
- Named theory/fragment and a proof that the model satisfies it.
- Antecedent and negated consequent witnesses.
- Non-vacuity: an actual decision, affected person, and triggered condition where relevant.
- List of full-theory requirements omitted or violated.
- A repaired comparison when this clarifies the missing bridge.

## Prototype obligations

First implement C3 with substantive operational definitions for assignment, appeal, and remedy capacity. Only then assess whether extension to C1/C2 adds distinct findings. Countermodels are not consistency proofs of every theory variant; each variant needs its own explicit witness or a verified construction from another witness.


## Prototype 0.7 C6 disposition

C6 is implemented in Participation.lean under I21. The named participation fragment has actual accepted and faithfully recorded recommendations, local record amendment, distinct input records and a pair of different final outcomes when no institutional override is used. The central rule can still select either final outcome for every local proposal. The paired binding rule retains the same input/record/amendment functions and supplies final control. Both have joint non-vacuous witnesses with the earlier person-facing and oversight fragments. This is not full subsidiarity, and it does not complete C5.


## Prototype 0.11 C1 disposition

C1 is checked under I25's minimal notice interpretation. The notice contains retrievable, numerically consistent decision information, an actual commitment list and genuine identified service contacts. The known institution has internal case allocation, but the disclosed service contact is not the actual denial assignee. The assignee's identity is missing. The case satisfies that explicit disclosure fragment and violates the stronger identifiable-responsibility requirement. A repaired notice publishes the actual assignee, with allocation, promises, score/cutoff/result and channels preserved. A general same-person bridge and a non-vacuous satisfying case accompany the separation. Stronger transparency definitions that require an identified actual assignee are not refuted. The same package supplies the bounded T10 declaration/provision comparison; C4/C5 remain active.


## Prototype 0.12 C4 disposition

The named antecedent fragment is retrievable, truthful arithmetic explanation plus the existing responsibility/appeal/remedy-capacity checklists. Two Bool-indexed benefits applications have the same verified score 60, the same cutoff 50, and different online/assisted intake channels. Under the explicitly adopted case policy, that channel is irrelevant: awards should be channel invariant and should follow the cutoff applied to the verified base score. A disclosed 15-point assisted-intake penalty yields grant/denial and violates both tests. The denied applicant is actually affected, excluded and high-impact; no Justice=False label is used. Removing the penalty supplies both tests and a non-vacuous satisfying case, while assignment, identification, appeal/correction channels and relevant scores remain fixed. The award and therefore exclusion/harm facts can change. This is one bounded C4 package. It refutes neither explanations that include successful normative justification nor all possible fairness criteria. C5 remains separate and active.


## Prototype 0.13 C5 disposition

DistributedControl.lean supplies the required actual composition. Bool roles are distinct operator and independent board; their separate hold inputs can each change an unpaused contested denial to paused with the other released. The protocol is an OR of external holds, initially ignoring the recorded local request. Requests are genuinely accepted, recorded and amendable, but changing them has no pause effect for any external configuration. Thus even this limited local action is unavailable; no Agency=False predicate is used. The repaired protocol additionally honors a local pause request and retains both external intervention powers. Joint release with no local request permits resumption, excluding an always-paused repair. Both versions have joint witnesses with the same original high-impact, affected denial, broad-appeal/harm-remedy fragments and an actionable independent board under the declared intervention proxy. The request-handling fragment is weaker than C6's conditional outcome-influence fragment; no inheritance of full participation is asserted. This is a hypothetical temporary-pause capacity result, not final benefit authority, successful correction, universal decentralization failure or full subsidiarity. All six fixed C questions now have bounded witnesses; incomplete positive targets remain active.
